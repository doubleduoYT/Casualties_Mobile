Casualties: Unknown Mobile — HGSoft (DoubDu)

Casualties: Unknown Mobile is an independent, fan-made Android port of Casualties: Unknown, originally created by Orsoniks. The port is developed by HGSoft (DoubDu).

Download all versions ↗ Join the Discord server ↗

Features

  • Mobile-exclusive touch controls and interface
  • Haptic feedback and a low-end performance mode
  • Plaza and Exploration online modes in supported builds
  • Server-side progress saving for Exploration mode
  • Korean localization and improved multilingual font compatibility
  • Ongoing compatibility updates for the original game's 7.0.1 medical systems

Current listed release

  • Version: 10.7.0 (version code 10700)
  • Platform: Android 6.0 or later (API 23+), ARM64
  • APK size: about 170 MB

Some uploaded versions, including v8.1, are reported as unplayable. Multiplayer may require the matching Windows build distributed by the project. Check the release information before installing or playing online.
