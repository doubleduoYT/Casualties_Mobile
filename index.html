04 / QUICK ANSWERS

Before you
head out.

Is this an official version of Casualties: Unknown?+

No. It is an independent fan-made Android port by HGSoft (DoubDu), not affiliated with or endorsed by the original creators or publisher.

Who made the original game?+

Casualties: Unknown was originally created by Orsoniks. This Android port is a separate project developed by HGSoft (DoubDu).

Where can I find the latest Android build?+

Build availability and supported versions may change. Check the project Discord for current distribution information and compatibility notes.

Does multiplayer work with every version?+

No. Multiplayer compatibility depends on the game build. The project README notes that the matching Windows build distributed by the project may be required.

모바일 포팅판

Casualties: Unknown을 안드로이드에서 즐길 수 있도록 HGSoft (DoubDu)가 개발하는 비공식 팬 포팅 프로젝트입니다. 모바일 전용 조작 버튼과 UI, 햅틱 피드백, 저사양 모드, Plaza와 Exploration 온라인 모드가 포함되어 있습니다. 지원 버전에서는 Exploration 진행 상황이 서버에 저장됩니다.

현재 등록된 최신 버전은 v10.7.0 (ARM64, Android 6.0 이상)이며 APK 크기는 약 170MB입니다. 업데이트와 호환 정보를 확인한 뒤 설치해 주세요.

원작은 Orsoniks가 만들었습니다. 이 모바일 포팅판은 원작과 별개의 프로젝트이며, Orsoniks 또는 Oro Interactive와 제휴·승인 관계가 없습니다. 원작의 자산과 지식재산권은 해당 권리자에게 있습니다.

일부 배포 버전(예: v8.1)은 실행할 수 없는 것으로 안내되어 있습니다. 설치 전 Discord에서 최신 배포 정보와 호환 버전을 확인해 주세요. 멀티플레이에도 프로젝트가 배포하는 호환 Windows 버전이 필요할 수 있습니다.
