- APK: [GitHub Releases에서 다운로드](https://github.com/doubleduoYT/Casualties_Mobile/releases/download/v10.7.0/CasualtiesUnknownMobile-MP-ARM64_v10.7.apk)

- 배포와 호환 정보: [프로젝트 Discord](https://discord.gg/Rjkj854cgg)
